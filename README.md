# energsertifikatai.lt

Modernizuota ir mobiliesiems optimizuota svetaines versija.

## Failai
- `index.html` – pagrindinis puslapis
- `styles.css` – dizainas ir responsive taisykles (desktop, plansete, telefonai 360–430 px)
- `script.js` – mobilus meniu ir animacijos
- `modernus-namas.webp` – optimizuota pagrindine nuotrauka
- `favicon.svg` – svetaines piktograma
- PDF – ekspertes darbo reglamentas

Mobiliajame variante pritaikytas iPhone safe-area, 3:2 hero vaizdas, mobilus meniu, lankstus tekstu ir korteliu mastelis bei fiksuotas skambinimo mygtukas.
